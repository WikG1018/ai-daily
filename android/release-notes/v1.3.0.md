## 新增
- **应用内更新**：设置 → 关于 → 检查更新，显示新版本、大小和更新内容，一键下载并调起系统安装
- 下载有进度，可取消；离开页面也会在后台继续，完成后通知你
- 每天打开 app 时自动检查一次（可在「关于」里关闭），首页出现「发现新版本」横幅，可忽略此版本
- 国内网络：版本信息走 GitHub Raw / jsDelivr，安装包在 GitHub 直连失败或太慢时自动切换加速镜像
## 安全
- 只接受本仓库 GitHub Release 的安装包，仅限 https
- 安装前校验 SHA-256 和签名证书，不一致直接中止并删除
- 从不静默安装，每次都由系统安装器让你确认
## 说明
- v1.2.0 及更早版本没有自动更新，需要手动装一次 v1.3.0，之后就能在 app 里更新
- 首次安装更新时，小米 / 澎湃 OS 会要求允许「安装未知应用」，按提示开启即可
